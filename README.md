Anonymous Feedback & Chat Bot


Асинхронный Telegram-бот на базе aiogram 3.x и aiosqlite, предназначенный для отправки и получения анонимных сообщений с поддержкой двусторонних диалогов через Reply и административным модулем деанонимизации.


🌟 Ключевые возможности:

Персональные ссылки: Автоматическая генерация уникальных диплинков (t.me/bot?start=USER_ID) для шершинга в соцсетях.
Поддержка любых медиа: Пересылка текста, фото, видео, голосовых и видеосообщений (кружочков).
Непрерывный анонимный диалог: Возможность отвечать на анонимки через стандартный Telegram Reply без раскрытия личности.
Админ-инструменты (/who): Возможность деанонимизации отправителя по конкретному сообщению (доступно только спискам админов).
Автоматическое обслуживание БД: Фоновая автоочистка записей старше 30 дней для оптимизации дискового пространства.


🛠 Технологический стек
 
Язык: Python 3.10+
 Фреймворк: aiogram 3.x
 База данных: SQLite + aiosqlite
 Управление состоянием (FSM): MemoryStorage


🚀 Быстрый старт

1. Клонирование репозитория и установка зависимостей:
git clone https://github.com/IvanBroYTBoss45/-
cd -
python -m venv venv
source venv/bin/activate
pip install aiogram aiosqlite


2. Настройка переменных окружения:
Укажите ваш токен и ID администратора в конфиге или окружении:
export BOT_TOKEN="your_telegram_bot_token"
ADMIN_IDS = [123456789]

3. Запуск бота:
python main.py


🏗 Архитектура базы данных


Для связывания входящих анонимных сообщений с исходными отправителями используется SQLite-таблица anon_messages со следующими полями:
 recipient_chat_id (INTEGER) — Chat ID получателя анонимки
 recipient_msg_id (INTEGER) — Message ID доставленного сообщения
 sender_id (INTEGER) — Настоящий Telegram ID отправителя
 full_name (TEXT) — Имя отправителя в Telegram
 username (TEXT) — Юзернейм отправителя (при наличии)
 language_code (TEXT) — Языковой код клиента
 is_premium (INTEGER) — Наличие подписки Telegram Premium
 created_at (TIMESTAMP) — Время отправки сообщения


📖 Команды бота

 /start — Получить свою персональную ссылку для приема анонимных сообщений.
 /start <user_id> — Начать процесс отправки анонимки выбранному пользователю.
 /who (только для ADMIN_IDS) — Деанонимизировать отправителя (вызывается ответом на анонимное сообщение).
